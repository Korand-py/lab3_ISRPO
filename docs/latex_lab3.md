### 2. Блочная формула
Пример сложной блочной формулы.

\[\int_{a}^{b} \sqrt{\frac{x + \alpha}{y^n}} \, dx\]

---

### Три конструкции из списка:
1. **Дробь:** `\frac{...}{...}`
2. **Корень:** `\sqrt{...}`
3. **Греческие буквы:** буква альфа `\alpha`
4. **Степень:** `y^n`
5. **Индекс:** `\int`
