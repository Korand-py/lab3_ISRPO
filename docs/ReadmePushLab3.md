# Описание пуша!

## git init - создание локального репозитория
## git add README.md - добавление README в git
## git status - статус git репозитория
## git commit -m "Initial commit: created README.md for Lab3" - первый коммит
## git remote add origin https://github.com/Korand-py/lab3_ISRPO.git - подключение онлайн репозитория
## git push -u origin master - пуш коммита
